Femmini TECH

Dispensador Automatizado de Productos de Higiene Femenina

Hardware Embebido

  • Arduino Uno: Procesamiento autónomo.
  • RFID MFRC522: Lectura de credenciales.
  • Ultrasonido HC-SR04: Control de stock (15 cm).
  • Servo SG90: Sistema Biela-Manivela.
  • OLED SSD1306: Pantalla informativa 0.96".

Software & Sistema

  • Python 3 & Tkinter: Interfaz gráfica de control.
  • Puerto Serie: Comunicación UART a 9600 baudios.
  • Persistencia CSV: Historial de entregas.
  • C++ Embebido: Control en microcontrolador.

Impacto e Innovación

  • Acceso ágil y automatizado a productos esenciales.
  • Monitoreo preventivo contra desabastecimiento.
  • Gabinete modular en madera con acabado institucional.
